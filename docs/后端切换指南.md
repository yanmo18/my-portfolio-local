## 二、后端改动

### 后端仓库

`https://github.com/yanmo18/my-portfolio-backend`

### 需要配置的地方

#### 1. 环境变量 `.env`

```env
# 数据库连接（MySQL）
DATABASE_URL="mysql://用户名:密码@host:3306/数据库名"

# JWT 密钥（生成随机字符串）
JWT_SECRET="你的随机密钥，至少32位"

# 端口
PORT=5000
```

#### 2. 数据库

**方式 A：免费 MySQL（推荐）**
- [PlanetScale](https://planetscale.com/) - 免费 1GB
- [Railway](https://railway.app/) - 免费 500MB
- [Neon](https://neon.tech/) - 免费 3GB

**方式 B：阿里云/腾讯云**
- 学生优惠几块钱一个月

#### 3. Prisma 模型

如果数据结构有变化，修改 `prisma/schema.prisma`

```prisma
model Project {
  id        String   @id @default(cuid())
  title     String
  cover     String?
  techStack String   // JSON 字符串
  github    String?
  features  String   // JSON 字符串
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
```

#### 4. 路由（一般不用改）

后端仓库的路由已经写好了：
- `/api/profile` - 个人信息
- `/api/project` - 项目
- `/api/award` - 奖项
- `/api/experience` - 经历
- `/api/auth` - 登录（未来扩展）

## 三、后端部署

### 部署方式

| 方式 | 难度 | 费用 | 推荐度 |
|------|------|------|--------|
| Vercel | 简单 | 免费 | ⭐⭐⭐⭐ |
| Railway | 简单 | 免费额度 | ⭐⭐⭐⭐ |
| Sealos | 简单 | 按量 | ⭐⭐⭐ |
| 阿里云函数计算 | 中等 | 按量 | ⭐⭐ |
| 阿里云 ECS | 复杂 | 贵 | ⭐ |

### Vercel 部署步骤

1. 注册 [Vercel](https://vercel.com/)
2. 连接 GitHub 仓库
3. 设置环境变量（DATABASE_URL, JWT_SECRET）
4. 点 Deploy

**Vercel 会自动：**
- 检测是 Express 项目
- 安装依赖
- 运行 Prisma 迁移
- 启动服务

**API 地址格式：**
```
https://my-portfolio-backend.vercel.app
```

## 五、后悔药（回滚）

如果切换后出问题，回滚很简单：

1. 把 `API_BASE` 改回 `https://lcnmaohntx.sealosbja.site`
2. 把路径去掉 `/api` 前缀
3. 推送即可

**不会影响任何数据，只是切换了 API 来源。**
